## Project Assignment

[indent] The execution and delivery of SecureCAT is built around five project roles distributed among the three capstone team members to cover all software engineering and academic research requirements. This division of labor separates project management and documentation from core software architecture, programming, and testing, so each member can focus on their expertise. David, who has the primary systems development background, takes the roles of Lead Developer and Programmer as well as System Analyst and Designer, ensuring that the advanced cryptographic, computer vision, and offline capabilities are aligned architecturally and implemented correctly. Jaypee serves as Project Manager to coordinate schedules, communicate with institutional stakeholders, and manage resource constraints, while sharing Technical Writer and Documenter responsibilities with Christine. Christine serves as Quality Assurance Tester to independently design test cases, coordinate user acceptance testing, and lead the usability and workload evaluations. The specific functions for each role are detailed in Table 1.

Table 1. Project Roles and Responsibilities

| Roles | Name | Functions |
| :--- | :--- | :--- |
| Project Manager | Jaypee | Coordinates project activities; communicates with adviser and campus stakeholders; manages overall timeline, task checklist, and project resources. |
| System Analyst and Designer | David | Analyzes user requirements; designs system architecture, database schema, and multi-tenant isolation layers; designs security models and interface mockups. |
| Lead Developer and Programmer | David | Develops all core system modules; implements backend services and frontend components; writes and executes automated unit and integration test suites. |
| Quality Assurance Tester | Christine | Develops usability and workload test cases; coordinates pilot testing; administers SUS and NASA-TLX evaluations; documents, tracks, and validates resolved defects. |
| Technical Writer and Documenter | Jaypee and Christine | Prepares the research manuscript, compiles references, conducts formatting QA, and writes technical manuals and user guides. |
