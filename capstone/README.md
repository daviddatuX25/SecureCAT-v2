# SecureCAT Capstone Directory Index

This directory serves as the centralized repository for all BSIT Capstone-related documents, guidelines, and pathways for **"SecureCAT: A Role-Based College Admission Testing System for the Guidance and Registrar Offices at ISPSC Tagudin."**

---

*   [**GUIDE-1-FORMATTING.md**](./GUIDE-1-FORMATTING.md)

    *   *Purpose:* Chapter 2 methodology content requirements (Research Design, Software Model, Project Plan, Instruments, Data Analysis).
*   [**GUIDE-4-AIDLC-DEFENSE.md**](./GUIDE-4-AIDLC-DEFENSE.md)
    *   *Purpose:* Panel defense strategy for the AIDLC software model — citations, scripts, case studies.

    *   *Purpose:* Complete pre-submission checklist for formatting, content, and defense readiness.
