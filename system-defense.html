Background

The College Admission Test process at ISPSC Tagudin

school

The College Admission Test (CAT) is a critical gateway for prospective students seeking enrollment at ISPSC Tagudin. Managing this process efficiently is essential for a seamless applicant experience.

warning

Traditionally, this process involves paper forms, manual scheduling, scattered spreadsheets, and fragmented communication between applicants, proctors, and administrators.

lightbulb

SecureCAT digitizes the entire CAT pipeline — from online application to automated scheduling, real-time proctoring, and AI-powered applicant support.

Project Goals

Objectives

General Objective

To develop SecureCAT — a role-based web application that streamlines the College Admission Test process at ISPSC Tagudin from applicant registration through exam scheduling, proctoring, scoring, and result release, grounded in Information Assurance and Security principles.

Specific Objectives

  • Digitize applicant registration and application management
  • Implement automated exam scheduling with room assignment
  • Enable real-time proctor attendance tracking
  • Automate score computation and result sheet generation
  • Provide role-based access control for all user types
  • Deliver AI-powered applicant query support via AI Companion
  • Send real-time notifications for exam events and status updates
  • Generate printable result sheets with counselor recommendations
